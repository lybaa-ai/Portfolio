# LYBA — Futuristic AI Portfolio V3

Built with pure HTML, CSS and vanilla JavaScript.

## Design direction
This version combines the supplied NOVA GLASS reference aesthetic with the content from the LYBA portfolio:
- light futuristic glassmorphism
- silver/chrome typography
- icy blue + soft violet accents
- interactive AI core
- subtle 3D tilt
- cursor glow
- animated counters and skill bars
- responsive mobile navigation
- project, skills, journey and contact sections

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Customize
Update:
- GitHub / LinkedIn URLs
- profile/CV if you add one
- project links
- any text in `index.html`
- colors/spacing in `css/style.css`

No build step is required.
